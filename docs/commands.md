# Commands

## pull

```
src pull <package>
src pull <git-url>
```

Downloads source code.

---

## search

```
src search <query>
```

Searches the registry.

---

## info

```
src info <package>
```

Displays package metadata.

---

## list

```
src list
```

Lists installed packages.

---

## update

```
src update
src update <package>
```

Updates one or every installed package.

---

## remove

```
src remove <package>
```

Deletes an installed package.

---

## help

Displays help.

---

## version

Displays version information.
