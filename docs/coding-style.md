# Coding Style

## Naming

Classes

```
PackageDownloader
ManifestParser
```

Functions

```
downloadFile()
removePackage()
```

Variables

```
packageName
downloadSpeed
```

Constants

```
constexpr int Width = 40;
```

## Formatting

- Four spaces
- Opening braces on new lines
- One class per file
- One responsibility per class

## Philosophy

Prefer readable code over clever code.

Keep functions small.

Keep components independent.
